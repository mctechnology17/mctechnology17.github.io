Política de privacidad

Última actualización: 12 de noviembre de 2026

Quién es el responsable

MC Technology es el canal y proyecto personal de Marcos Chow Castro. Para cualquier consulta sobre privacidad: marcos@mctechnology17.com.

Esta web (mctechnology17.com)

  • No usa cookies, analítica, publicidad ni formularios, y no carga nada de terceros: las fuentes y los iconos se sirven desde la propia web.
  • No recoge ni guarda datos personales de quien la visita.
  • Está alojada en GitHub Pages. Como cualquier servidor web, GitHub puede registrar datos técnicos de la visita (por ejemplo, la dirección IP) para mantener y proteger el servicio. Su tratamiento se explica en la declaración de privacidad de GitHub.
  • Los enlaces llevan a otras plataformas (YouTube, Instagram, PayPal y demás), cada una con su propia política.
  • Si me escribes por correo, uso tu dirección y tu mensaje solo para responderte.

La aplicación «MC Technology»

«MC Technology» es una herramienta interna que uso para publicar y programar mis propias publicaciones en mis propias cuentas (por ejemplo YouTube, Instagram y Facebook) y para ver sus estadísticas. No está abierta al público: solo la uso yo.

  • Qué datos trata: los permisos de acceso a mis propias cuentas, el contenido que publico (vídeos, imágenes y textos) y las estadísticas de mis propias publicaciones y canales.
  • Datos de otras personas: la aplicación no recoge, guarda ni comparte datos personales de otros usuarios. Si muestra estadísticas, son cifras agregadas que facilita cada plataforma.
  • Para qué: solo para publicar mi contenido y analizar su rendimiento.
  • Dónde se guarda: en un servidor propio y privado. Los archivos que se van a publicar pasan de forma temporal por un almacenamiento en la nube para que la plataforma de destino pueda descargarlos, y se borran después de publicarse.
  • Con quién se comparte: con nadie. No se venden ni se ceden datos, ni se usan para publicidad.
  • Servicios de Google (YouTube): el uso de la información recibida de las API de Google cumple la política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado. La aplicación usa los servicios de la API de YouTube; se aplican las condiciones de YouTube y la política de privacidad de Google.
  • Cómo se retira el acceso: desconectando la cuenta en la aplicación o desde los ajustes de seguridad de cada plataforma (en Google: myaccount.google.com/permissions). Al hacerlo, los permisos guardados se eliminan.

Tus derechos

Si crees que tengo algún dato tuyo, puedes pedirme acceso, corrección o borrado escribiendo a marcos@mctechnology17.com. También puedes reclamar ante la autoridad de protección de datos que te corresponda.

Cambios

Si esta política cambia, la versión nueva se publicará en esta página con su fecha.
